# ASHFALL 0.8.9.46 — Nomade en expédition

Base : 0.8.9.45, avec les quatre secteurs, les salles variables et le correctif d’extraction.

## Changements
- Nouveau rendu low-poly procédural du **joueur en expédition seulement**, cohérent avec la capuche sable, le visage sombre, le sac anthracite, les bottes et la tenue du Nomade du refuge.
- Orientation visuelle vers l’ennemi visible le plus proche lorsque le combat automatique vise, sinon selon le déplacement ; animation de marche réduite au minimum à l’arrêt.
- Pistolet, SMG, arme longue et arme énergétique différenciés visuellement à partir du nom réellement équipé.
- Dessin vectoriel intégré : aucune image supplémentaire à charger, fonctionne hors-ligne avec le cache de la PWA.
- Le Nomade original du refuge et les sprites des ennemis sont **inchangés**.
- **Aucune modification** des collisions, vitesse, dégâts, inventaire, sauvegardes ou extraction.

## Vérifications attendues
Ouvrir une nouvelle expédition, marcher dans quatre directions, tirer avec un pistolet puis un fusil, traverser une salle en L, extraire, fermer puis reprendre le jeu.
