ASHFALL PWA 0.1 — prototype autonome

CONTENU : index.html, css/game.css, js/game.js, manifest.webmanifest, service-worker.js, icons/*.png.

INSTALLATION SUR GITHUB PAGES (depuis Safari iPhone) :
1. Créer un dépôt GitHub public nommé ashfall.
2. Décompresser ashfall-pwa.zip dans Fichiers.
3. Dans le dépôt GitHub, ajouter à la racine TOUS les fichiers ET répertoires, en conservant les chemins.
4. Settings > Pages > Deploy from a branch > main / (root) > Save.
5. Quand le site est publié, ouvrir https://VOTRE-NOM.github.io/ashfall/ dans Safari.
6. Partager > Sur l'écran d'accueil > Ouvrir comme app > Ajouter.

Ne chargez PAS le ZIP seul dans GitHub : il faut publier les fichiers extraits, avec index.html à la racine.
Ne publiez aucun fichier contenant un secret. Attention : le dépôt est public.
Les sauvegardes du prototype à l'intérieur de ChatGPT ne sont pas automatiquement importables : elles peuvent avoir un schéma différent.
Le premier chargement doit être effectué connecté à Internet pour permettre le cache hors ligne.
La sauvegarde locale iOS n'est pas garantie indéfiniment : exporter un code de sauvegarde et le conserver dans Notes ou Fichiers.
La PWA est un prototype, non un jeu iOS natif ni une version commerciale stabilisée.
