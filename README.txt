ASHFALL Alpha 0.8.9.5 — LOOT ECONOMY FIX

Base : Alpha 0.8.9.4 (économie et bonus d’expédition conservés).

Nouveautés :
- Revente des objets trouvés plafonnée selon leur rareté : Commun 25–50, Inhabituel 50–100, Rare 100–200, Épique 200–350, Légendaire 400–650 crédits.
- Revente d’un objet acheté plafonnée à 25 % de son prix d’achat. Compatibilité avec les anciens objets issus du catalogue marchand.
- Même tarif de revente depuis la réserve et depuis le Comptoir. Confirmation et protection des objets assurés sur les deux voies.
- Affichage de la valeur réelle de récupération dans la réserve et le marchand.
- Aucune suppression ni réinitialisation du stockage local. Clé de sauvegarde inchangée : ashfall_pwa_v1.

INSTALLATION : copier les huit fichiers du jeu à la racine du dépôt GitHub Pages.
